### 🚀 About Me
I am an **Embedded Systems** and **Firmware Engineering** enthusiast with a technical background in **Mechatronics** and currently pursuing a degree in **Information Systems**. My primary focus is low-level development and optimization for ARM microcontrollers.

- 🔧 Currently deep-diving into the **STM32** ecosystem.
- 🔋 Passionate about **Low Power Design** and Wearables.
- 📈 Studying **Digital Signal Processing (DSP)** on ARM processors.
- 🇧🇷 Based in Rio de Janeiro, Brazil.

### 🌟 Featured Projects

#### ⌚ [epaper-watch-fw](https://github.com/whittejr/epaper-watch-fw)
Firmware for an **STM32WB-based** watch using an E-paper display for ultra-low power consumption. Features include fall detection (accelerometer) and health monitoring.

#### 🏗️ [Templates](https://github.com/whittejr/Templates)
A standardized **Docker/Dev Container** development environment for STM32, streamlining build and debug tools for consistent project setups.

#### 📊 [dsp_on_arm_processors](https://github.com/whittejr/dsp_on_arm_processors)
A dedicated study and implementation of Digital Signal Processing algorithms optimized for ARM hardware.
